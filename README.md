# ⚡ SBK — Storm Breakers clan app (Windows)

Private desktop app for the Storm Breakers [SBK] Fortnite clan.

- Cinematic intro on launch + a full "Welcome to the Storm" cinematic for new members
- Sign up / sign in with email (sends a confirmation email), clan-only with approval
- Chat channels: announcements, general, looking-for-squad, clips, wins
- 📸 Screenshot (F8) and 🎥 screen recording (F9), works in-game
- Staff panel: approve, ban, promote Leaders, handle reports
- Built-in safety: age check (13+), profanity filter, report button

## Download
Go to **Releases** → download **SBK-Setup.exe**.

## Build
Every push to `main` builds the Windows app automatically (GitHub Actions).
